# Рабочее место четырёх участников

У каждого человека один личный агент. Модель участник выбирает в своих настройках. Плагины, подписки, API-ключи и настройки чужих машин этим PR не устанавливаются.

1. Получить свою копию репозитория и проверить доступ к Issues и PR.
2. Прочитать AGENTS.md и docs/AGENT_CONTRACT.md; определить роль по указанию человека.
3. Подготовить локальный ROLE.local.md; не коммитить и не выдумывать логин.
4. Установить зависимости по README; mock не требует модельного ключа.
5. Передать агенту назначенный Issue и зависимости. Для чужого ревью начать отдельную сессию.

Ни один конкретный плагин не является условием чтения протокола. Дополнительные навыки устанавливаются локально после проверки происхождения и разрешений. Не отмечать вход GitHub, плагины или техническую изоляцию настроенными без проверки.

GitHub сам не запускает локальные агенты. Чтение сообщений, статусы и передача результата — по контракту. Старые указания про пять человек и дочерних агентов заменены согласованным составом.
