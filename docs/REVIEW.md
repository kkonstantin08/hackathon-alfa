# Независимое ревью

Нормативный порядок: [AGENT_CONTRACT.md, раздел 7](AGENT_CONTRACT.md#7-независимое-ревью).

## Пакет для ревью

Issue и пять критериев; ожидаемое поведение; полный diff; точные base/head SHA; необходимые соседние исходники и контракты; результаты проверок и ограничения; имя независимого ревьюера.

Ревью выполняет существующий личный агент участника в новой сессии без редактирования, коммитов и публикации исправлений. Технический доступ только на чтение используется, где доступен; текстовая инструкция не доказывает изоляцию. Пятый постоянный агент не создаётся.

## Отчёт в PR

- Ревьюер: имя, роль, известные среда/модель; неизвестное не выдумывать.
- Проверенные base/head SHA и область анализа.
- Вердикт: PASS / CHANGES_REQUIRED / INCOMPLETE.
- Замечания: P0/P1/P2, файл:строка, сценарий, последствия, доказательство, направление исправления.
- Реальные проверки и существенные ограничения.

Пустой ответ, неполный diff и тайм-аут не означают PASS. После изменения кода прежний отчёт не подтверждает новый head. Исполнитель проверяет находки и объясняет отклонённые; несогласованные P0/P1 блокируют слияние, решения по P2 явно фиксирует человек.

GitHub Approval даёт другой человек после чтения отчёта. Публикация этих инструкций не устанавливает автоматический AI-бот или защиту main. ADMIN-01 требует реальных административных настроек.

## Источники подходов

- [Every ce-code-review](https://github.com/EveryInc/compound-engineering-plugin/blob/main/docs/guides/ce-code-review.md): проверки по рискам и проверка находок.
- [OpenClaw autoreview](https://github.com/openclaw/agent-skills/blob/main/skills/autoreview/SKILL.md): независимая проверка конкретной версии, явный неполный результат.
- [Sentry find-bugs](https://github.com/getsentry/skills/blob/main/skills/find-bugs/SKILL.md): место, последствия и доказательство.

Принципы адаптированы в инструкции; внешние плагины автоматически не устанавливаются.
