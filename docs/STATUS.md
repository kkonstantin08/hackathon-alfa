# Где мы сейчас и что делаем дальше

Обновлено 20.10.2026, МСК. В команде четыре человека. План обсуждается в [Issue #1](https://github.com/kkonstantin08/hackathon-alfa/issues/1) и [draft PR #2](https://github.com/kkonstantin08/hackathon-alfa/pull/2).

## Сейчас

Есть репозиторий, проверки его структуры и черновики документов. Кода приложения ещё нет. По ссылкам кейса найдены три CSV и девять PDF; их содержимое пока не проверено. Четыре стартовые задачи ещё не назначены людям и не созданы отдельными Issues.

| Участник | Его самостоятельный результат |
| --- | --- |
| A | Получение признаков компании из исходного CSV |
| B | Получение платежей и связей компании из исходных CSV |
| C | Поиск фрагментов в аналитике банка со ссылкой на документ и страницу |
| D | Небольшой набор новостей и пробный ответ модели на своих примерах |

Каждый использует исходные материалы и свои примеры. Результаты коллег для завершения этих задач не нужны. Подробные задания и объяснение их пользы: [ROLES.md](ROLES.md).

## После сдачи четырёх задач

1. Показываем, что получилось у каждого.
2. Обсуждаем архитектуру до общей сборки: как соединить части, хранить данные и получать ответ модели.
3. Создаём отдельную задачу и соединяем части в один запуск без интерфейса.
4. Проверяем другую компанию, новую новость и отсутствие нужных данных.
5. Распределяем дальнейшую работу по навыкам. Делаем интерфейс, backend, чат и многошаговую логику агента, затем готовим запуск для жюри.

## Что нужно определить ближайшим обсуждением

- Кто берёт A, B, C и D, сколько у каждого времени и когда показываем результаты.
- Дедлайн сдачи и время демонстрации.
- Доступ к исходным файлам и разрешённому модельному API. Ключ отключается после окончания приёма решений.

Хостинг и адрес демо пока не выбраны. Архитектура и API остаются предложениями. Проверки репозитория не подтверждают качество данных и ответов модели; это проверяем при выполнении задач.
