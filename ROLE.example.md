# Личная роль — копировать в ROLE.local.md

ROLE.local.md не коммитится. Не угадывать неизвестный GitHub-аккаунт.

- Человек: имя участника.
- Роль: A Александр / B Константин / C Алексей / D Тимофей.
- GitHub-логин: только проверенный; пока можно не заполнять.
- Основной Issue: ссылка.
- Режим: реализация / независимое ревью чужого PR.

Прочитать AGENTS.md и docs/AGENT_CONTRACT.md. Для ревью использовать новую сессию, без редактирования. Дополнительные постоянные агенты не запускаются. Merge и deployment требуют отдельных команд.
